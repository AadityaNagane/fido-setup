  1. 1FIDO · Windows, macOS or Linux

Part 1

FIDO

Pick your laptop's operating system below and follow the steps exactly.

  1. Download the setup file

    Choose which version of FIDO you want and download its .bat file.

    Option A

    Standard FIDO

    Download for Windows setup_fido.bat
    Option B

    Bharat Gen variant

    Uses a bigger model, so it takes longer to download and install.

    Download for Windows .bat file

  2. Turn off Smart App Control (Windows 11 only)

    ⚠ Warning

    Smart App Control is a Windows security feature. If you do not feel comfortable turning it off, you can wait for the workshop and we will help you there.

    If you turn it off, please turn it back ON after the workshop (steps at the end of this Windows section).

    Smart App Control can block the files FIDO needs to run properly.

    1. Click the Start Menu at the bottom of your screen, type Windows Security, and open it.
    2. Click App & browser control on the left side.
    3. Click Smart App Control settings.
    4. Select Off.

    If you do not see Smart App Control settings, you are either on Windows 10 or it is already off. You can skip this step.

  3. Run the setup

    1. Go to your Downloads folder and double-click the .bat file you just downloaded. A black command window will open.
    2. Wait until the window says the setup is finished. Do not close the window early, even if it looks stuck for a minute.
    3. Once the setup is finished, the next steps to run FIDO will appear right below that in the same black window. Follow those exact steps.
    Closed the black window by mistake?

    Just double-click the .bat file again and wait. If all the files are already there, it will not download them again. It will just tell you FIDO is installed and show you the next steps.

After the workshop

Turn Smart App Control back on

  1. Open Windows Security from your Start Menu.
  2. Click App & browser control.
  3. Click Smart App Control settings.
  4. Select On.

If On is greyed out, run Windows Update first, then try again.

  1. Download the setup file

    Choose which version of FIDO you want and download its .sh file.

    Option A

    Standard FIDO

    Download for Mac .sh file
    Option B

    Bharat Gen variant

    Uses a bigger model, so it takes longer to download and install.

    Download for Mac .sh file

  2. Open your Terminal

    Press Command and Space at the same time to open Spotlight Search. Type Terminal and press Enter.

  3. Run the setup file

    You will run the .sh file you downloaded using drag and drop.

    1. In your Terminal window, type bash followed by a single space. Do not press Enter yet.
    2. Open your Downloads folder and find the .sh file you downloaded in Step 1.
    3. Click and drag that file into the Terminal window and let go. This pastes the exact file path for you.
    4. Now press Enter.
    5. Follow any on-screen instructions in the Terminal window to complete the installation.
    $ bash /Users/yourname/Downloads/setup_fido.sh
# ↑ typed "bash " yourself, the path came from dragging the file in
